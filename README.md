# Guess the Number

A simple command-line game in Python. The computer picks a secret number between
1 and 100, and you try to guess it. After each guess it tells you whether the
number is higher or lower, until you find it or run out of chances.

## How to Play

Make sure you have Python installed, then:

```bash
git clone <repository-url>
cd guess-num
python main.py
```

Pick a difficulty (Easy, Medium or Hard), type your guesses, and follow the hints.
